# GasControl

## Descrição

O GasControl é um sistema web voltado ao monitoramento e controle de gases em ambientes agrícolas, com foco em estufas. O projeto simula a análise de concentração de gases (como CO₂) para auxiliar na produtividade e na tomada de decisão.

O sistema conta com páginas institucionais, autenticação de usuários e um painel com visualização de dados e simulações.

## Funcionalidades

* Cadastro e login de usuários
* Dashboard com visualização de dados
* Painel administrativo
* Simulador de concentração de gases
* Navegação entre páginas institucionais (home e sobre)

## Estrutura do Projeto

public/

index.html → Página inicial
login.html → Tela de login
cadastro.html → Tela de cadastro
dashboard.html → Dashboard principal
painel.html → Painel de controle
simulador.html → Simulador de gases
sobre.html → Página institucional

js/ → Scripts JavaScript (dashboard, gráficos, painel, simulador, usuário)
styles/ → Arquivos CSS (global, home, dashboard, simulador, etc.)
assets/img/ → Imagens do sistema
